# Antigravity master prompt

Operate BoundaryLens as a gated autonomous engineering workflow.

Read AGENTS.md first.

For each phase:
1. Discover inputs.
2. Plan.
3. Implement.
4. Execute.
5. Test.
6. Visually inspect where relevant.
7. Audit against AGENTS.md.
8. Document.
9. PASS or BLOCK.

You must verify:
- dataset provenance
- CRS
- schema
- geometry
- raster alignment
- 3D validity
- AI evaluation
- source conflicts
- confidence
- human-verification gate

Never silently invent missing values.

Never turn:
- DEM into DSM,
- height into exact floor count,
- AI prediction into legal fact,
- a proposed vertical linkage into an official 3D ULPIN.

When a required input is unavailable, use NOT_DETERMINABLE or a clearly labelled synthetic fixture and stop before making an unsupported production claim.

Do not mark a task complete while any critical test fails.
